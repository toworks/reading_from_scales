# reading_from_scales

Программа чтения данных из весовых приборов и логированние в sql - reading from scales

## Управление программным обеспечением

- установка: reading_from_scales.exe -s install
- удаление: reading_from_scales.exe -s uninstall
- запуск: reading_from_scales.exe -s start
- остановка: reading_from_scales.exe -s stop
- перезапуск: reading_from_scales.exe -s restart
